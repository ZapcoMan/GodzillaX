# 主题系统修复说明 (2026-09-14)

> GodzillaX UI 主题系统在引入 FlatLaf 3.7.2 后出现一系列崩溃与显示问题，本次针对 **主题选择、主题切换、颜色自适应、资源加载** 做了一次性彻底修复。

---

## 一、背景

项目将 FlatLaf 从 3.2.5 升级到 3.7.2，并引入 `lib/flatlaf-demo-1.4.jar`（旧版 1.4 demo）作为主题选择面板来源。但 1.4 旧 demo 与 3.7.2 核心库版本严重不匹配，加上 `ModernUITheme` 颜色配置时机不当、资源目录不规范，导致运行时接连出现 `NullPointerException`：

- 点击「目标 → 添加」「管理 → 生成」菜单时 `FlatComboBoxUI.applyStyle` 抛 `this.padding is null`
- 打开「配置 → 程序配置」时 `IJThemesPanel.setTheme` 抛 NPE（`$ColorPalette.table` 变量解析失败）
- 切换主题后菜单/按钮背景色不变，字看不清
- JDK17 下打开程序配置时 `FlatListUI` 抛 `this$0.list is null`

---

## 二、问题与根因

### 1. flatlaf-demo 1.4 与 3.7.2 版本冲突

| 现象 | 根因 |
|------|------|
| 启动后点「添加」「生成」菜单 → `FlatComboBoxUI.applyStyle` NPE (`this.padding is null`) | `ApplicationContext.initUi()` 末尾调用旧 demo 的 `IJThemesPanel.setTheme(...)`，1.4 旧 API 在 LAF 切换过程中破坏了 FlatLaf 内部 padding 字段初始化时序 |
| 打开「程序配置」→ `IJThemesPanel.setTheme:288` NPE | 旧 demo 携带的 IntelliJ JSON 主题引用了 3.7.2 已移除的 `$ColorPalette.table` 变量，`IntelliJTheme.setup` 解析失败 |
| `ModernUITheme.applySavedTheme` 走 JSON 资源分支找不到文件 | 路径 `/com/formdev/flatlaf/intellijthemes/themes/*.json` 在 3.7.2 中不存在（3.7.2 用主题类而非 flatlaf-core 里的 json 资源） |

### 2. 资源加载返回 null

| 现象 | 根因 |
|------|------|
| `DynamicUpdateClass.readDefaultClassName` → `getResourceAsStream("assets/classNames.txt")` 返回 null | 资源放在 `src/main/java/shells/payloads/java/assets/` 下 |
| `TerminalSettingsProvider.<clinit>` → `new ZipInputStream(null)` NPE（被 catch） | 资源放在 `src/main/java/shells/plugins/generic/seting/assets/` 下 |
| 共同根因 | Maven 默认只复制 `src/main/resources` 下的非 `.java` 文件到 `target/classes`，`src/main/java` 下的资源被忽略 |

### 3. 主题切换颜色不自适应

| 现象 | 根因 |
|------|------|
| 切换主题后菜单/按钮背景固定不变、字看不清 | `ModernUITheme.apply()` 原顺序是「先配置颜色 → 后切 LAF」，配色时读到的是旧主题颜色 |
| 选择高亮、边框等停留在旧主题 | 大量颜色硬编码固定值（如 `new Color(60,110,180,60)`、`Color.WHITE` 按钮前景、PopupMenu 灰边框）不随主题深浅变 |
| 预览切换主题后颜色不刷新 | `ThemesPanel.applyTheme` 切 LAF 后没有重新应用 `ModernUITheme` 的颜色配置 |

### 4. FlatListUI 模态对话框 NPE (JDK17)

```
NPE: Cannot invoke "javax.swing.JList.getModel()" because "this.this$0.list" is null
  at BasicListUI$Handler.valueChanged
  ← FlatListUI.lambda$createListSelectionListener$2
  ← setValueIsAdjusting ← BasicListUI$Handler.mouseReleased
```

全项目只有 `ThemesPanel` 的 `themeList` 用 `JList`。根因：FlatLaf 的 `FlatListUI` 在模态 `JDialog` 首次显示时，selection listener lambda 引用的 `BasicListUI$Handler` 其外层 UI 实例的 `list` 字段为 null（UI 时序问题，JDK17 特有，JDK8 不触发）。

## 三、修复方案

### 1. 移除旧 flatlaf-demo，自实现 ThemesPanel

- 删除 `lib/flatlaf-demo-1.4.jar` + `pom.xml` 移除 flatlaf-demo 依赖
- 新建 `core/ui/component/dialog/ThemesPanel.java`：基于 flatlaf 3.7.2 原生 API
  - `FlatAllIJThemes.INFOS` 枚举所有 IntelliJ 主题类 + 内置 FlatLaf（Light/Dark/IntelliJ/Darcula）
  - 统一用 `lafClassName` 实例化主题，`FlatLaf.setup` 安装
- `ApplicationContext`
  - 移除 `IJThemeInfo` / `IJThemesPanel` import
  - `saveUi(IJThemeInfo)` → `saveUi(String lafClassName)`，清除旧 `ui-resourceName` 拋留
  - `initUi()` 不再调旧 demo 的 `setTheme`，主题安装完全交由 `ModernUITheme.applySavedTheme()`
- `ModernUITheme.applySavedTheme`：移除 JSON 资源分支，统一用 `lafClassName` 实例化；启动时清除数据库残留的旧 `ui-resourceName`

### 2. 资源加载修复

`pom.xml` `<build>` 新增 `<resources>` 配置：

```xml
<resources>
    <resource>
        <directory>src/main/resources</directory>
    </resource>
    <resource>
        <directory>src/main/java</directory>
        <excludes>
            <exclude>**/*.java</exclude>
        </excludes>
    </resource>
</resources>
```

把 `src/main/java` 下所有非 `.java` 文件也复制到 `target/classes`，`classNames.txt` / `alacritty.zip` 等资源可正常加载。

### 3. 颜色自适应重构 (`ModernUITheme.java`)

- `apply()` 重排顺序：`applySavedTheme()`（先切 LAF）→ `configureAll()`（基于新 LAF 配色）→ `ensureRequiredDefaults()`
- 抽出公开 `configureAll()`：聚合所有 configure* 方法，供主题切换后重应用
- 硬编码颜色改为基于当前 LAF 派生：
  - 选择高亮（Table/Tree/List）→ `withAlpha(accentColor(), 60)`
  - PopupMenu 边框 → `UIManager.getColor("Component.borderColor")`
  - SplitPaneDivider.draggingColor → `withAlpha(accentColor(), 60)`
- 按钮前景 `Color.WHITE` → `contrastForeground(accent)`（按强调色亮度自动选黑/白）
- 新增私有工具：`accentColor()` / `withAlpha()` / `contrastForeground()`
- `ThemesPanel.applyTheme` 切 LAF 后调 `ModernUITheme.configureAll()` + `invokeLater(updateComponentTreeUI)` 刷新主窗口与对话框

### 4. JList → JComboBox

把 `ThemesPanel` 主题选择从 `JList` 改为 `JComboBox`，避开 `FlatListUI` 在模态对话框的 mouseReleased/selection 时序路径：
- `DefaultComboBoxModel<ThemeInfo>` + `JComboBox` + `setRenderer(ThemeCellRenderer)`
- `ActionListener` 替代 `ListSelectionListener` 做实时预览
- `ComboBox.padding` 已由 `ModernUITheme.ensureRequiredDefaults` 兜底，无 `FlatComboBoxUI` padding NPE

### 5. 主题保存后自动重启

- `ApplicationContext.restart()`：用 `java.home/bin/java[.exe]` + `-Dfile.encoding=UTF-8` + `-classpath java.class.path` + 主类 `core.ui.MainActivity` 构造 `ProcessBuilder`，`directory(user.dir)`，`start()` 后 `System.exit(0)`
- `AppSeting.updateThemesButtonClick`：保存成功后提示「主题已保存，程序将自动重启以应用新主题」，用户点确定后 `dispose()` + `ApplicationContext.restart()`

---

## 四、ThemesPanel 渲染器（易用性）

为让用户直观区分主题深浅，自定义 `ThemeCellRenderer`：

- 每项显示 **16×16 圆角色块图标**：深色主题画深灰底 + 蓝色强调条，浅色主题画浅灰底 + 蓝色强调条
- **友好主题名**：去掉冗余的 `Flat ` 前缀（`Flat Arc Dark` → `Arc Dark`）
- **深/浅标记文字**：`[深色]` / `[浅色]`
- 顶部 `JLabel` 提示：「选择主题可实时预览；确定后点下方「修改」保存，重启程序后永久生效」
