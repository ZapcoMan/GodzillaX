# Godzilla Web Shell 管理工具 - 完整功能逻辑分析

## 📋 项目概述
Godzilla 是一个功能强大的 Web Shell 管理工具,支持多种语言(Java/PHP/ASP/C#)的 WebShell 管理和渗透测试功能。

---

## 🚀 启动流程

### 1. 主入口 (MainActivity.main)
```
src/main/java/core/ui/MainActivity.java:374-385
```

**启动步骤:**
1. **初始化 UI** - `ApplicationContext.initUi()`
   - 设置 FlatLaf 现代化主题
   - 配置圆角、阴影等 UI 特性
   - 加载用户保存的主题偏好

2. **初始化静态资源** - `initStatic()`
   - 创建菜单栏
   - 创建插件菜单
   - 创建右键菜单

3. **应用配置检查** - `ApplicationConfig.invoke()`
   - 从 Gitee/GitHub 获取配置文件
   - 验证 JAR 文件哈希值(SHA-512)
   - 检查新版本
   - 显示公告和微信群二维码

4. **创建主窗口** - `new MainActivity()`
   - 初始化数据库连接
   - 加载所有 Shell 列表
   - 构建主界面布局

## 🏗️ 核心架构

### ApplicationContext (应用上下文)
```
src/main/java/core/ApplicationContext.java
```

**核心功能:**
1. **模块扫描与加载**
   - `scanPayload()` - 扫描所有 Payload 模块(Java/PHP/ASP/C#)
   - `scanCryption()` - 扫描加密模块(AES/XOR等)
   - `scanPlugin()` - 扫描插件模块
   - `scanPluginJar()` - 加载外部插件 JAR

2. **全局配置管理**
   - 字体设置 (`initFont`)
   - HTTP 请求头 (`initHttpHeader`)
   - 代理配置 (`getProxy`)
   - HTTPS 证书生成 (`genHttpsConfig`)

3. **工厂方法**
   - `getPayload(payloadName)` - 获取指定 Payload 实例
   - `getCryption(payloadName, cryptionName)` - 获取加密器
   - `getAllPlugin(payloadName)` - 获取所有插件

## 🔐 加密与 Payload

### Payload 类型
```
shells/payloads/
├── java/
│   ├── JavaDynamicPayload      # Java 动态类加载
│   ├── JavaRawPayload          # Java 原始代码
│   └── JavaCustomClassPayload  # Java 自定义类
├── php/
│   └── PhpDynamicPayload       # PHP eval/assert
├── asp/
│   └── AspDynamicPayload       # ASP Execute
└── csharp/
    └── CShapDynamicPayload     # C# Assembly.Load
```

### 加密方式
```
shells/cryptions/
├── JavaAes/       # AES 加密 (Java)
├── phpXor/        # XOR 加密 (PHP)
├── aspXor/        # XOR 加密 (ASP)
└── cshapAes/      # AES 加密 (C#)
```

**加密流程:**
```
1. 用户输入密码和密钥
2. 选择加密算法
3. 生成加密后的 Shell 代码
4. 客户端使用相同算法解密通信数据
```

## 🎯 典型使用流程

### 场景 1: 添加并使用 WebShell

```
1. 生成 Shell
   ├─ 管理 → 生成
   ├─ 选择 Payload (如 JavaDynamicPayload)
   ├─ 选择加密 (如 JavaAes)
   ├─ 设置密码和密钥
   └─ 生成并部署到目标服务器

2. 添加 Shell
   ├─ 目标 → 添加
   ├─ 填写 URL/密码/密钥
   ├─ 选择 Payload 和加密
   ├─ 测试连接
   └─ 保存到数据库

3. 使用 Shell
   ├─ 双击 Shell 进入管理界面
   ├─ 命令执行 Tab - 执行系统命令
   ├─ 文件管理 Tab - 上传/下载文件
   ├─ 数据库 Tab - 连接数据库
   └─ 插件 Tab - 使用高级功能
```

### 场景 2: 内网渗透

```
1. 建立代理
   ├─ 进入 Shell
   ├─ 找到 SocksProxy 插件
   ├─ 设置监听端口 (如 1080)
   └─ 启动代理

2. 配置浏览器
   ├─ 设置 Socks5 代理
   ├─ 地址: 127.0.0.1:1080
   └─ 访问内网资源

3. 端口转发
   ├─ 使用 PortMap 插件
   ├─ 转发内网端口到本地
   └─ 直接访问内网服务
```

### 场景 3: 持久化控制

```
1. 内存 WebShell
   ├─ 使用 MemoryShell 插件
   ├─ 注入到目标应用内存
   ├─ 无需写入文件
   └─ 重启后失效

2. 真实终端
   ├─ 使用 RealCmd 插件
   ├─ 建立交互式 Shell
   └─ 长期使用更稳定
```

## 📝 扩展开发指南

### 添加新插件
1. 创建类实现 `Plugin` 接口
2. 添加 `@PluginAnnotation` 注解
3. 实现 `init()` 和 `getView()` 方法
4. 编译打包为 JAR
5. 在程序中加载

### 添加新 Payload
1. 创建类实现 `Payload` 接口
2. 添加 `@PayloadAnnotation` 注解
3. 实现命令执行/文件操作等方法
4. 编写对应的 WebShell 模板
5. 添加到 payloads 目录

### 添加新加密
1. 创建类实现 `Cryption` 接口
2. 添加 `@CryptionAnnotation` 注解
3. 实现 encrypt/decrypt 方法
4. 编写客户端和服务端代码
